## Getting One

![Photo of the Raytac MDBT50Q-RX USB dongle](/images/dongle.jpg)

Right now, you'll have to buy a Raytac MDBT50Q-RX and flash it yourself. It's best to buy from [Adafruit](https://www.adafruit.com/product/5199) as they sell versions pre-flashed with the TinyUF2 boot loader which makes it easy to flash with the Arduino IDE or the command line.
